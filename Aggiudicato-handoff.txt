# Aggiudicato — handoff for a new model

Swiss cantonal auction reader. Name: **Aggiudicato**. UI language: **Italian**. Do not rewrite it. Continue this app.

The product reads public UEF auctions and helps a serious buyer decide, in 20 seconds: **offer up to X because Y, but check Z**. It does **not** bid or take payment. Bids happen on the official canton site.

Stack: TanStack Start/Router/Query, React 19, Tailwind v4, Better Auth, Postgres/PGLite. Auth and database are **on**.

## Verdetto (the Pro product)

The old “Dossier / Approfondimento AI / 6-bar score on the lot page” is **gone**. Catalog may still show a small Pro index tile (`scoreLot` in `auction-card.tsx`). The lot page uses `AuctionVerdictPanel` only.

Engine: `buildAuctionVerdict(auction)` in `src/lib/auctions/intel.ts`. Pure, deterministic, no LLM, no id-hash. UI: `src/components/auction-verdict.tsx`. Types: `AuctionVerdict` in `src/lib/auctions/types.ts`.

Verdicts: `BUY` | `WATCH` | `PASS` | `INSUFFICIENT`.

All-in, in order:

1. Current hammer (or start if no bids).
2. + buyer premium **15%** if the notice does not state one. Declare it.
3. + transport: CHF 80 small/house, 450 vehicle, 900 machinery.
4. + a small restoration only if the text names a defect.
5. Prudent value = the lot’s `estimatedValue` if it exists, else `null`. Never invent a CHF market value for TI.
6. Low margin = prudent value − all-in.
7. Risk buffer = max(key risk, 10% of prudent value, uncertain transport).
8. `maxBidAllIn` = prudent value − buffer. `hammerMax` = that, minus fees, inverted for the 15% premium.
9. `walkAwayPrice` = `maxBidAllIn`.

Rules:

- `BUY` only if low margin > 0, no blocking gap, and either 2+ real comparables **or** a verifiable condition (km, hours, MFK, service stamps, perizia, box+papers, vacant).
- Never invent comparables (no fake AutoScout/Ricardo counts).
- `PASS` if the hammer is already at or above `hammerMax`, or the risk eats ≥40% of the low value.
- No stima and no comps → `INSUFFICIENT`.
- Headline is one cold Italian sentence with the price or the reason. Forbidden: interessante, potrebbe, l’AI ritiene, approfondimento, opportunità unica, da non perdere.
- Unknown number → `n.d.`. Money via `formatChf` in `src/lib/format.ts` (de-CH).
- “Vedi calcolo” opens an inline panel, not a modal: 5-line formula, assumptions, comparables, missing data.

Expected checks:

- Porsche 9002: **PASS**. Headline contains the bid and “chiavi / telaio”. Hidden/assumption says demo ZG. Not “rilancia 5%”.
- Attico 9001: **BUY** (mock stima, perizia and oneri on the text).
- Generic TI e-bike with no brand and no stima: **INSUFFICIENT**, copy says no perizia, no invented market CHF.
- Logged out: blurred/••• numbers, headline visible, button *Sblocca verdetto Pro* → `/prezzi`.
